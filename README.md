# Agente Inteligente para la Gestión de Citas Veterinarias


El proyecto aborda el diseño y la implementación de un agente basado en conocimiento para apoyar la gestión de citas veterinarias mediante reglas lógicas e inferencias.

## Objetivo
Representar el conocimiento de un dominio de gestión de citas veterinarias y desarrollar un agente capaz de analizar solicitudes, identificar conflictos y generar decisiones mediante reglas de inferencia.

## Contenido
- Modelado del conocimiento.
- Representación mediante predicados.
- Reglas de inferencia.
- Implementación del agente en Python.
- Simulación de reservas, cancelaciones y reprogramaciones.
- Actualización de la base de conocimiento.

## Tecnologías
- Python 3.12
- Visual Studio Code
- Jupyter Notebook
- Git y GitHub

## Ejecución
Abrir el archivo `agente_logico_microservicios.ipynb` en Visual Studio Code y ejecutar las celdas en orden.
